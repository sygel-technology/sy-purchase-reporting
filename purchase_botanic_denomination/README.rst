This module adds the botanic denomination menu entries to purchases.

It also adds the botanic denomination to the purchase report.

Usage
=====

To use this module, you need to:

1. Go to Purchase / Configuration / Botanic Denominations. Create your
   botanic demomination records
2. Go to Purchase / Products. Open a produc's form view. Fill the
   "Botanic Denomination" field
3. Go to Purchase / Orders. Sell a product with botanic denomination. Go
   to Purchase / Reporting / Purchase, you can filter and group the
   purchases by botanic denomination
